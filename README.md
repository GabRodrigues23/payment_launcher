# Payment Launcher

Aplicativo Flutter desenvolvido com o objetivo de estudo para integração com soluções de pagamento.

Este projeto tem como foco testar a comunicação entre aplicativos, simulando o envio de dados para um app de pagamento externo e o recebimento de respostas da transação.

Integração baseada na biblioteca:
https://github.com/TefIP/dart_tefip

> Projeto experimental, utilizado apenas para aprendizado.
